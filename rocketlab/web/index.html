FLIGHT MANUAL / 001

The rocket learns
what you reward.

This is a real Gymnasium LunarLander-v3 environment trained with Stable-Baselines3 PPO. The agent sees eight numbers, chooses one of four engine actions, and learns from the points it earns.

  1. Baseline. Train using the environment's original reward.
  2. Time cost. Charge a small fee each frame to discourage waiting.
  3. Break it. Pay for being upright and slow while airborne. This can make hovering more profitable than landing. It may take several seeds or longer training to emerge.
  4. Fix it. Use discounted potential differences, γΦ(next) − Φ(now), plus a time cost. The discounted shaping return telescopes instead of paying a fresh +1 every frame.

Read the base score. Training curves show both original and shaped rewards. Checkpoints are selected on five validation episodes, then tested on 20 different seeds without the reward wrapper. A mean base score of at least 200 meets this lab's solved criterion. Report several training seeds for stronger evidence.

The flight view replays real physics states from an evaluation episode. Its telemetry uses the environment's normalized coordinates and velocities; tilt is displayed in degrees. The episode limit is 1,000 frames at 50 Hz. Hovering is an experiment, never a guaranteed training outcome.

RUN YOUR OWN EXPERIMENT

Your computer.
Your reward function.

This hosted lab replays the real agents trained for this project. To train new policies or run new evaluations, download the Python project and launch its local dashboard.

Use Python 3.11, then run:

python3.11 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip swig
pip install -e .
rocketlab serve

The included README has complete setup instructions. The local dashboard adds live training, graceful stopping, fresh evaluations, and MP4 recording.
